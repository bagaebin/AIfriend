# AI 데이팅 아바타 게임 & VTuber 파이프라인 — 사양 모음

이 저장소는 브라우저 기반 “AI 데이팅 앱 + VTuber 아바타” 데모를 위한 경량 사양 세트를 담고 있습니다. 클라이언트의 실시간 처리와 서버의 OpenAI 오케스트레이션을 명확하게 분리해 테스트 가능하게 유지하는 것이 목적입니다.

## 문서 구성
- `architecture.md` — 엔드 투 엔드 시스템 구성, 데이터 흐름, 성능 가이드라인.
- `backend-api.md` — 텍스트·이미지 생성을 위한 Express API 계약 및 OpenAI 사용 규칙.
- `frontend-vtuber.md` — VTuber 파이프라인, 얼굴 추적, 표정 매핑, 메쉬 변형 지침.
- `session-flow.md` — 대화 흐름, 아바타 갱신 타이밍, 프롬프트 설계 기대치.

## 설계 목표
- **관심사 분리:** 클라이언트는 실시간 추적/렌더링을, 서버는 OpenAI 호출과 영속화를 담당합니다.
- **지연 시간 최소화:** 이미지는 프레임마다가 아닌 이벤트 기반으로 생성합니다. 얼굴 추적은 저해상도 입력과 최소 연산을 사용합니다.
- **교체 용이성:** 계약만 유지된다면 추적/렌더링/API 클라이언트를 독립적으로 교체할 수 있습니다.
